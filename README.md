# Сортування товарів(products-ordering)

Плагін "products-ordering" для CMS "Wordpres" розробляється з метою спростити сортування товарів у інтернет-магазинаг на базі плагіну "Woocommerce".

Вимогами до "products-ordering" є:
- можливість налаштовувати порядок відображення товарів у каталозі;
- всі товари без рейтингу мають відображатися найпершими, до отримання ними рейтингу;
- якщо у товарів однаковий порядок сортування, то сортування повинно відбуватися у порядку абетки за назвою товару.

Результат роботи буде зберігатися у каталозі: ```/plugins``` у архіві ```products-ordering.zip```
